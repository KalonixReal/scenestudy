# Hidden Figures — SceneStudy

A standalone, offline-capable essay study tool for the film *Hidden Figures* (2016): flashcards with spaced repetition (by character or essay tag), a 286-question essay-skills quiz (argument → evidence, technique → effect, analysis vs summary, barrier analysis, counter-claims…), scene matching in three modes (technique / big idea / essay tag), recall practice with per-scene essay angles, and a scene library organised by 16 color-coded essay tags (racism, sexism, segregation, intersectionality, solidarity and more).

Also included: **dark / light theme** (persisted per browser), **mastery-by-tag analytics** (weakest essay tags first), **Markdown study-notes export** (Notion/Docs-ready, includes your own recall notes), a **printable study pack** (evidence cards on paper), study streak tracking, a 7-day review forecast chart, full answer review after each quiz round, keyboard shortcuts (Space/1-3 for cards, 1-4/Enter for the quiz), and custom scene-sheet upload (JSON/CSV with an optional `tags` column) to study any film.
