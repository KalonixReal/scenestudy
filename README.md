# Hidden Figures — SceneStudy

A standalone, offline-capable essay study tool for the film *Hidden Figures* (2016): flashcards with spaced repetition, a 286-question essay-skills quiz (argument → evidence, technique → effect, analysis vs summary, barrier analysis, counter-claims…), scene matching, recall practice, and a scene library organised by essay tags (racism, sexism, segregation, intersectionality, solidarity and more).

**Deploying (Cloudflare Pages):** this branch is the entire site — no build step, no dependencies.

- Build command: *(leave empty)*
- Build output directory: `/`
- Everything is inlined in `index.html`; it works offline once loaded.

Upload your own scene sheets (JSON/CSV with an optional `tags` column) to study any film.

The full development workspace lives on the `workspace` branch.
